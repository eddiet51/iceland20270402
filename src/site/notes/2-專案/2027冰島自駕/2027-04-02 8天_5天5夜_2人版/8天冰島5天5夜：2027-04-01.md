# 🇮🇸 冰島自駕 6 天 5 夜行程規劃 (04-02 ~ 04-07)

> [!NOTE] 備忘與注意事項
> - **藍湖溫泉**：04-06 (週二) 15:30 場次務必提前於官網預訂。

## 🏤 申根區入境：EES 及 ETIS


<div class="transclusion internal-embed is-loaded"><a class="markdown-embed-link" href="/_2人版/🏤 EES & ETIAS 入出境流程/" aria-label="Open link"><svg xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" class="svg-icon lucide-link"><path d="M10 13a5 5 0 0 0 7.54.54l3-3a5 5 0 0 0-7.07-7.07l-1.72 1.71"></path><path d="M14 11a5 5 0 0 0-7.54-.54l-3 3a5 5 0 0 0 7.07 7.07l1.71-1.71"></path></svg></a><div class="markdown-embed">




### EES & ETIAS 入出境流程

> [!INFO] **行程基本資訊**
> 
>   
> 
> - **去程路線**：高雄 (KHH) $\rightarrow$ 香港 (HKG) $\rightarrow$ 瑞士蘇黎世 (ZRH) $\rightarrow$ 冰島雷克雅維克 (KEF)
>     
>       
>     
> - **回程路線**：冰島雷克雅維克 (KEF) $\rightarrow$ 法蘭克福 (FRA) $\rightarrow$ 香港 (HKG) $\rightarrow$ 高雄 (KHH)
>     
>       
>     
> - **申根邊境點**：去程入境點為 **瑞士 (ZRH)**，回程出境點為 **德國法蘭克福 (FRA)**。
>     
>       
>     
> - **關鍵概念**：`ZRH ↔ KEF` 與 `KEF ↔ FRA` 皆屬於**申根區內航班**（視同國內線），無邊境海關。
>     
>       
>     

#### 核心機制快速對照

|**項目**|**ETIAS (歐洲旅行資訊及許可系統)**|**EES (出入境系統)**|
|---|---|---|
|**性質**|事先申請之電子旅行授權（類 ESTA）|邊境現場執行之生物特徵出入境紀錄|
|**辦理時間**|**出發前**（台灣線上完成）|**抵達 ZRH / 離開 FRA 現場**|
|**費用**|€20（效期 3 年）|免費|
|**運作方式**|綁定護照，航空公司系統連線確認|現場自助機台/海關：錄入指紋 + 面部特徵|

#### 去程入境流程 (KHH $\rightarrow$ HKG $\rightarrow$ ZRH $\rightarrow$ KEF)

![2-專案/2027冰島自駕/2027-04-02 8天_5天5夜_3人版/attachments/Pasted image 20260813160303.png](/img/user/2-%E5%B0%88%E6%A1%88/2027%E5%86%B0%E5%B3%B6%E8%87%AA%E9%A7%95/2027-04-02%208%E5%A4%A9_5%E5%A4%A95%E5%A4%9C_3%E4%BA%BA%E7%89%88/attachments/Pasted%20image%2020260813160303.png)

##### 1. 高雄小港機場 (KHH)

- **檢查重點**：**ETIAS 授權**
    
- **運作說明**：辦理 Check-in 時，航空公司地勤系統連線確認護照已綁定有效 ETIAS，方可開立全程登機證。

##### 2. 香港國際機場 (HKG)

- **運作說明**：純轉機安檢，不涉及申根區邊境，無須任何 EES/ETIAS 查驗。

##### 3. 瑞士蘇黎世機場 (ZRH) —— **申根區入境邊境（關鍵節點）**

- **檢查重點**：**EES 首次建檔 + ETIAS 現場核驗**
    
- **運作說明**：
    
    1. 下飛機後順著 `Transit / Exit (Non-Schengen to Schengen)` 指標前往邊境海關。
    2. 使用 **EES 自助機台** 掃描護照、拍攝面部照片並錄入指紋。
    3. 前往海關櫃檯，官員調閱 EES 與 ETIAS 資料，確認無誤後放行進入申根區。

##### 4. 冰島凱夫拉維克機場 (KEF)

- **運作說明**：此段航班（ZRH $\rightarrow$ KEF）為申根區內航班，抵達後**無任何海關護照查驗**，直接提取行李入境。

#### 回程出境流程 (KEF $\rightarrow$ FRA $\rightarrow$ HKG $\rightarrow$ KHH)

![2-專案/2027冰島自駕/2027-04-02 8天_5天5夜_3人版/attachments/Pasted image 20260813160734.png](/img/user/2-%E5%B0%88%E6%A1%88/2027%E5%86%B0%E5%B3%B6%E8%87%AA%E9%A7%95/2027-04-02%208%E5%A4%A9_5%E5%A4%A95%E5%A4%9C_3%E4%BA%BA%E7%89%88/attachments/Pasted%20image%2020260813160734.png)

##### 1. 冰島凱夫拉維克機場 (KEF)

- **運作說明**：辦理報到與托運行李後，進行常規安檢。因前往法蘭克福屬申根區內航班，**離開冰島時不會經過海關護照查驗櫃檯**。

##### 2. 德國法蘭克福機場 (FRA) —— **申根區出境邊境（關鍵節點）**

- **檢查重點**：**EES 離境紀錄**
- **運作說明**：
    1. 抵達 FRA 後，依照 `Non-Schengen Transit` 或 `Gates B / Z`（非申根登機區）指標前進。
    2. 行經申根出境海關，使用 **EES 快速通關閘門或海關櫃檯** 進行面部辨識與護照掃描。
    3. 系統自動比對入境時間並完成 **EES 離境自動登記**（確保未超過申根區 90 天停留上限），隨後前往非申根區登機門。

##### 3. 香港國際機場 (HKG) / 高雄小港機場 (KHH)

- **運作說明**：香港順利轉機，抵達高雄後走台灣自動通關 (e-Gate) 入境返家。
    
#### ⚠️ 轉機與實務注意事項

> [!WARNING] **法蘭克福 (FRA) 出境轉機時間預留**
> 
>   
> 
> - **FRA 機場龐大且動線複雜**：法蘭克福機場動線較長，加上需通過 **EES 申根出境海關** 與 **非申根區二次安檢**，建議回程在 FRA 的轉機時間至少預留 **2 小時** 以上。
>     
>       
>     
> - **去程 ZRH 轉機時間**：去程需執行 EES 首次生物特徵建檔（拍照+指紋），建議 ZRH 轉機時間預留 **2 ~ 2.5 小時**。
>     
>       
>     

> [!TIP] **離線備份與文件**
> 
>   
> 
> - 將 ETIAS 核准信件 PDF 檔連同護照影本儲存在手機或電子裝置中，以備航空公司人工查驗時出示。
>
